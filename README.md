# tiktool Homebrew tap

```sh
brew install --cask tiktool/tap/mouse-keys-record-replay
```

Mouse Keys Record Replay records mouse and keyboard input with one shortcut and replays it once or on a loop.
Site: https://mouserec.com - source: https://github.com/tiktool/mouse-keys-record-replay

After installing, allow the app under System Settings > Privacy & Security > Accessibility and Input Monitoring.

The cask is bumped automatically from the latest GitHub release.
